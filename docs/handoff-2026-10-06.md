### 헬스 체크 (순서대로)
```bash
curl -s -m 5 http://127.0.0.1:8323/ -o /dev/null -w "ASR %{http_code}\n"
curl -s -m 5 http://127.0.0.1:8124/ -o /dev/null -w "pt-agent %{http_code}\n"
# TTS E2E(역검증 포함 — 응답이 RIFF WAV인지 + 프록시 로그에 LANG-OK인지)
curl -s -m 180 -o /tmp/postboot.wav -w "TTS %{http_code}\n" \
  -X POST https://bc.wizbase.ai.kr/tts-api/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-bf16","input":"재부팅 후 점검입니다. 안녕하세요 반갑습니다.","voice":"sohee","language":"ko","response_format":"wav","instruct":"","temperature":0.15,"repetition_penalty":1.15,"verify_lang":true}'
file /tmp/postboot.wav   # RIFF ... WAVE audio 여야 함
tail -3 /Users/wizbase/works/bc-ai/mlx-tts-proxy.log   # REQ ... verify=1 + LANG-OK 확인
```
- 첫 TTS 요청은 모델 웜업으로 수십 소요될 수 있음(정상). **bad-wav가 나오면 response_format 누락부터 의심**
